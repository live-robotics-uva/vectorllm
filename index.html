VectorLLM

Language-Controllable Autonomous Driving via Vectorized Scene Grounding

VectorLLM represents map geometry and agent motion as discrete vector tokens inside a pretrained language model, creating one interface for grounded reasoning, question answering, trajectory generation, and counterfactual language control.

Abstract

Ground driving language in precise scene structure

Natural language provides a flexible interface for humans to interact with autonomous vehicles. However, the effectiveness of this interaction relies on a driving model’s language grounding and controllability. Recent works have leveraged vision-language models as backbones but remain limited in grounding driving scenes with language. VectorLLM introduces a vectorized paradigm that grounds vectorized driving scenes with pretrained large language models. Agent motions and map elements are represented as discrete tokens and aligned with language in the LLM’s latent space. This directly incorporates low-level driving information into the LLM so its reasoning and language generation capabilities can operate over a vectorized scene. Across trajectory prediction, question answering, scene edits, and counterfactual instructions on WOMD and nuScenes, VectorLLM improves language grounding and demonstrates stronger controllability than the evaluated alternatives.

Motivation and contributions

A language model that can directly address scene elements

Image tokens, projected object features, and coarse text descriptions provide semantic context, but can obscure road geometry, vehicle dynamics, and agent interactions. VectorLLM instead inserts structured driving information into the model’s vocabulary.

1. Ego-centric vectorization

Coordinates are translated and rotated into the ego vehicle’s local frame. Static map polylines and dynamic agent histories are both expressed as ordered two-dimensional displacement vectors. Local map context is filtered around the ego trajectory, and curvature-adaptive resampling uses shorter segments in curved regions and longer segments on near-straight roads.

2. Discrete scene vocabulary

A k-disks procedure builds a shared vocabulary of 1,024 displacement tokens from WOMD. The selected vocabulary reconstructs WOMD road polylines with mean pointwise error below 0.03 m. Beam-search assignment reduces drift along long polylines, while semantic markers distinguish maps, roads, ego motion, agent identity, and agent type.

3. One serialized context

Map blocks, ego history, surrounding-agent histories, and an optional question or instruction are concatenated into one sequence. The original language vocabulary is preserved; vector and special tokens expand both the input embedding matrix and the language-model output head.

4. LLM-centered architecture

The model uses a pretrained decoder-only LLM without a separate map encoder, motion encoder, scene-to-LLM projector, or trajectory decoder. All original parameters, language embeddings, added vector embeddings, and the expanded output head are trainable.

5. Grounded chain of thought

Reasoning traces follow a driving-oriented sequence: identify ego motion, select relevant map and nearby-agent evidence, reason about interactions and feasible maneuvers, then support the answer or trajectory. Vector-token references keep the intermediate reasoning tied to the serialized scene.

6. Goal-conditioned trajectory decoding

The model first regresses three sparse future waypoints from designated hidden states. Trajectory target positions then use bidirectional attention and are decoded in parallel. Predicted vector tokens are mapped back to displacement centroids and cumulatively summed into metric coordinates.

Training

Learn scene structure first, then solve driving tasks

Stage I · Vector-token pretraining

Standard next-token prediction over serialized driving scenes exposes the pretrained LLM to map and motion structures as ordinary token sequences.

Stage II · Multi-task fine-tuning

Question answering, goal prediction, and trajectory generation are trained together. Language and vector outputs use cross-entropy; the continuous waypoint goal head uses an L2 loss.

Grounded supervision generation

WOMD supplies map elements, agent histories, and future trajectories. A deterministic pipeline extracts motion events, map context, spatial relations, interactions, counts, and goal-oriented cues. Rule-based analysis determines the labels and relevant scene evidence; Qwen3-4B-Instruct-2507 only paraphrases those facts into natural-language QA pairs and reasoning traces. It is not asked to infer geometry or behavior from raw trajectories.

Reference implementation setting

The main experiments use Qwen3-0.6B, a 1,024-token scene vocabulary, and a 12,288-token training context. Only 0.6% of WOMD training scenes exceed that context limit and are dropped.

Evaluation

Grounding, prediction, and counterfactual control

WOMD is the primary source for pretraining and multi-task fine-tuning. nuScenes tests transfer to another dataset and supports language-conditioned control experiments.

Language grounding

Question answering on WOMD-Reasoning and nuScenes-QA tests whether language can retrieve the correct scene information from vector tokens.

Trajectory generation

Marginal ego-trajectory prediction on WOMD and nuScenes tests whether the token representation preserves enough low-level motion information.

Controllability

Custom counterfactual sets edit WOMD scenes or issue alternative nuScenes language instructions to test whether trajectories move toward the intended behavior.

The perception-based VectorLLM+MapTR variant replaces annotated HD-map polylines with MapTR vectors predicted from multiview images; the remaining pipeline is unchanged.

Results · Controllability

Respond to changed scenes and changed instructions

Each counterfactual test supplies three intended future waypoints. A waypoint is hit when at least one of six generated trajectories passes within 1.0 m. The reported score is the average fraction of goals reached.

Counterfactual scene edits on WOMD

The evaluation changes lane geometry, removes or inserts behaviorally relevant agents, or alters ego-motion history. These interventions test whether prediction follows the edited map, interaction constraints, and recent motion rather than copying the original future.

Ablations and analysis

Correct grounded reasoning matters

Removing chain of thought or corrupting half of its underlying scene facts harms both trajectory prediction and question answering. The gain therefore does not come merely from generating more intermediate text.

Latent-space alignment

t-SNE visualizations place maneuver language near related trajectory tokens and map-context language near relevant map tokens. This is qualitative evidence that the shared context learns semantically meaningful vector-language relationships.

Attention-based grounding

Selected language tokens attend to scene regions relevant to the question or instruction, and the attended regions shift under counterfactual commands. The paper treats these maps as qualitative grounding evidence, not definitive causal attribution.

Unseen scene captioning

Without captioning supervision, the model can produce descriptions combining ego motion, road context, and nearby-agent interactions. This is presented as qualitative generalization rather than a benchmarked captioning result.

Backbone and data scaling

Larger fully fine-tuned backbones generally improve instruction control, but gains become modest at moderate scale. Increasing counterfactual training data produces a clearer, more consistent improvement across short and long horizons.

Limitations

Current boundaries

  • No joint raw-perception training. VectorLLM can consume maps from a perception front end, but reconstruction noise and mismatch reduce performance.
  • Temporal localization remains difficult. QA failures can identify the correct behavior while missing its precise time boundaries.
  • Trajectory errors can accumulate. Early prediction errors are especially consequential in fast-moving scenes.
  • Large counterfactual changes remain challenging. The model can resist instructions that require a substantial departure from learned behavioral priors.

# VectorLLM project site

This repository is an outline for the VectorLLM project website. It intentionally
contains placeholders instead of project claims, paper text, media, or copied
template content.

## Site outline

- Hero: project title, authors, affiliations, and links
- Abstract
- Project overview
- Method / system design
- Execution or generation process
- Benchmarks and tasks
- Comparative results
- Real-world or qualitative experiments
- Design choices and efficiency
- Citation

## Local preview

Serve this directory with any static HTTP server and open `index.html`.
